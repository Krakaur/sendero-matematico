# Sendero 0.3.1 — cálculo con un toque y tiempos distinguibles

Cada respuesta correcta en cálculo avanza automáticamente al siguiente ejercicio. Desaparece la confirmación adicional entre aciertos. Después de un error, la solución continúa visible y destacada hasta que el estudiante selecciona la respuesta correcta. El modo de razonamiento conserva su explicación y avance deliberado.

Los informes incorporan aciertos iniciales por minuto de respuesta, junto con precisión, cantidad de observaciones y exclusiones, separados por contenido y dificultad. Se registra el tiempo hasta la primera respuesta sin sumar la lectura posterior de la solución. Las pistas, interrupciones y registros antiguos quedan fuera de esta tasa; sus resultados de práctica permanecen disponibles. No es una carrera cronometrada ni una medida validada de capacidad matemática general.

La importación Android compara valores numéricos de JSON independientemente de su representación interna, para evitar falsos conflictos al recibir dos veces el mismo informe. Los conflictos de contenido real continúan rechazándose.

APK nativa para Android 14–16, sin navegador, WebView ni permiso de internet. Conserva paquete y firma de las versiones nativas anteriores. Windows x64 conserva el motor y los recursos incorporados; no requiere instalar un navegador. Los instaladores de Windows siguen sin firma comercial. El banco de problemas es el mismo de 0.3.0.

Publicación experimental. La revisión con niños y teléfonos físicos continúa pendiente. La fórmula, las observaciones directas de Arcademics y los límites de interpretación se documentan en [Fluidez y medición](https://github.com/Krakaur/sendero-matematico/blob/main/docs/ARCADEMICS-FLUIDEZ-Y-MEDICION.md).
