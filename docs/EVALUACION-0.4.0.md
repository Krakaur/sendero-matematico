# Evaluación técnica y de interacción 0.4.0

## Tres ciclos web

**Ciclo 1, Chromium, 390 × 844.** Creación de perfil, carrera, error, solución visible, corrección con un toque, pausa, ocho respuestas, resultado, modalidad tranquila y recarga sin conexión. Sin errores de ejecución. La revisión visual identificó exceso de altura para pantallas menores y un desbordamiento del botón de sonido introducido al actualizar su etiqueta.

**Ciclo 2, Chromium, 360 × 640.** Se redujeron carriles y espacios, manteniendo respuestas de al menos 50 píxeles CSS. La primera comprobación situó el borde inferior de las respuestas en 645.75 píxeles; falló el criterio de 640. Se corrigió el encabezado y se restauró el icono de sonido con etiqueta accesible. La repetición pasó el criterio geométrico y la secuencia funcional completa. La explicación de un error puede requerir desplazamiento adicional; permanece visible hasta corregir.

**Ciclo 3, Firefox, 1366 × 768.** Escena y respuestas en columnas, carrera completa, revisión de captura, corrección, pausa y recarga offline. Sin errores de ejecución. Se separó además la presentación estadística por carrera/práctica para no ocultar diferencias de condiciones. La evaluación es técnica y heurística: no se asigna una puntuación inventada de atractivo o satisfacción infantil.

## Lógica, datos y distribución

La suite Node contiene 31 pruebas de contenido, adaptación, informes, métricas, aislamiento, recuperación, agregación y entrega docente. Las pruebas del receptor usan HTTP real con base temporal, confirmaciones, deduplicación, rol y revocación. Una prueba adicional de navegador recorre envío ficticio, recepción docente, publicación local de tarea y copia protegida con nueva contraseña.

Android utiliza Java/Canvas/SQLite. El flujo comprueba compilación, ocho pruebas Java, lint, firma, tamaño, permisos y ausencia de referencias WebView; ejecuta cinco pruebas instrumentadas por API 34, 35 y 36 con Chrome/WebView deshabilitados y emuladores con 2 GiB de RAM. Comprueba actualización desde la versión pública 0.2.0 preservando perfil, contraseña y respuesta pendiente. La primera ejecución aprobada fue `35053106617`; su revisión visual motivó compactar la escena y evitar repetir la operación encima de la corrección. La ejecución final y hashes se consignan en el manifiesto de publicación.

Las pruebas Windows se realizan sobre el ejecutable empaquetado con un directorio de usuario exclusivo de ensayo. No se utilizan los perfiles reales del usuario. La copia portátil distribuye el mismo paquete de aplicación incluido en `win-unpacked`.

## Límites observados

No hay prueba física en el teléfono del usuario, consumo energético medido ni evaluación con niños. La base activa no está cifrada. Los respaldos Android y web no son intercambiables. Android no tiene narración ni entrega automática y su panel aún mezcla modalidades dentro de contenido/nivel. No hay servicio docente público, administración escolar completa ni revisión independiente del contenido ampliado. Los conteos y pruebas no acreditan cobertura curricular total, efectos educativos, equivalencia con Arcademics, anonimato garantizado o admisión en tiendas.
