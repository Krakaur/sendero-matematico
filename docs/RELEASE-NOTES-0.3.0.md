# Sendero 0.3.0 — cálculo y problemas sin conexión

Esta edición incorpora 6 270 enunciados, procedentes de 128 situaciones originales y 16 familias matemáticas. El banco está incluido: no se ejecuta IA en el dispositivo ni se consultan servicios de generación. La selección conserva historial, reduce repeticiones recientes y mantiene 1 574 problemas reservados para situaciones no practicadas.

La práctica de cálculo y el razonamiento progresan por separado. Se añade repaso programado de operaciones y una ampliación opcional de tablas con ambos factores del 1 al 20. Los informes muestran dimensiones de las actividades con barras y colores, e incluyen identificadores y explicaciones del banco.

## Descargas

`Sendero-Nativo-0.3.0.apk` es la aplicación Android 14–16 sin navegador ni WebView. Ocupa 386 882 bytes y no solicita permisos. Instalar sobre 0.2.0 conserva los perfiles; no es necesario desinstalar. `Sendero-Nativo-0.3.0.aab` es el paquete de distribución Android, no un instalador directo.

`Sendero-0.3.0-Windows-x64.exe` es la edición portátil de Windows, con el motor incluido y sin firma comercial. `Banco-Sendero-0.3.0.zip` contiene el catálogo CSV para revisión docente, el manifiesto y las condiciones de uso del banco; no se importa dentro de la app. `SHA256SUMS.txt` y `RELEASE-0.3.0.json` permiten verificar los archivos.

## Verificación y límites

Pasaron 18 pruebas Node, cinco pruebas Java y cuatro pruebas integradas en cada versión Android 14, 15 y 16. Se comprobó la actualización real desde 0.2.0, con conservación de perfil, contraseña y respuesta pendiente. También se comprobó una aventura web sin conexión y el banco en Windows empaquetado. Código Android compilado: `d38c3ce`; ejecución final: https://github.com/Krakaur/sendero-matematico/actions/runs/35027880412.

Es una versión experimental con revisión interna. La cobertura curricular es parcial; faltan revisión docente independiente, prueba física en teléfonos y evaluación con niños. Web y Windows conservan un perfil por instalación; las contraseñas pertenecen a la edición Android. La transferencia de informes sigue siendo manual. Los informes v2 requieren un receptor actualizado; se siguen admitiendo informes v1.
