# Sendero 0.4.0 — regata, perfiles y continuidad

La carrera incorpora tres rivales virtuales, posición, tiempo y puntos de juego; mantiene ocho operaciones de un mismo nivel y ajusta el siguiente recorrido según las respuestas. El cálculo conserva avance con un toque y solución destacada después del error. La modalidad tranquila y el taller de razonamiento permiten practicar sin competir.

Web y Windows incorporan perfiles locales con contraseña, respaldos cifrados, resultados más legibles y evolución por modalidad/contenido/nivel. Android añade respaldo protegido y escena nativa de carrera, sin WebView ni permisos de internet. El banco conserva el contenido anterior y suma 360 problemas: 6 630 entradas en total.

Se incluye un cliente web/Windows y receptor docente local con invitaciones, tareas, confirmaciones y reintentos. Se probó con registros sintéticos; no se ofrece alojamiento público ni se contrató un servicio. Android conserva intercambio manual por archivos.

La publicación incluye APK y AAB firmados, y Windows x64 portátil sin certificado comercial. Instala la APK sobre la versión nativa anterior para conservar datos; no desinstales primero. Para actualizar la web utiliza el aviso del juego o [Actualizar conservando datos](https://krakaur.github.io/sendero-matematico/actualizar.html). Una partida antigua continúa con su modalidad previa; selecciona Carrera para la siguiente aventura.

Pruebas: 31 Node, ocho Java, recorridos Chromium/Firefox, Windows empaquetado y cinco pruebas instrumentadas por Android 14–16. Consulta el manifiesto para el flujo final y hashes, y `EVALUACION-0.4.0.md` para incidencias y límites. Son pruebas técnicas, no una evaluación con niños.

La cobertura curricular permanece parcial; no se ha demostrado eficacia educativa. Investigación desactivada. La base activa no está cifrada. Respaldos Android y web/Windows no intercambiables. Android todavía no incluye narración ni filtros/series de resultados equivalentes a la web. No se publicaron versiones en Play Store/App Store ni se registró el software en el perfil curricular del autor.
